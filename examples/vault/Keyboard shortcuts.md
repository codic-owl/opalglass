# Keyboard shortcuts

## Workspace

- Ctrl O — browse for a vault folder
- Ctrl N — name a new note in the file tree
- Ctrl Shift N — name a new folder in the file tree
- F2 — rename the selected entry or active note
- Shift F10 — open the context menu for the tree selection
- Ctrl P or Ctrl F — search titles and contents
- Enter in search — open the first result
- Ctrl S — save the current note
- Ctrl Shift S — save a copy
- Ctrl W — save and close the current tab
- Ctrl Tab / Ctrl Shift Tab — next / previous tab
- Ctrl 1–8 / Ctrl 9 — numbered tab / last tab
- Ctrl E — cycle source, split, and reading views
- Ctrl Q — save all tabs and quit
- Escape — cancel naming, close a menu/dialog, or cancel dragging

## Mouse

Right-click a folder to create notes and folders inside it. Right-click the vault
name or empty space to create at the root. Right-click an entry to rename it or
choose a destination folder. Enter confirms a name; Escape cancels.

Drag files and folders onto a folder to move them, or onto the vault name to move
them to the root. Drag tabs to reorder them. Click a tab's × or middle-click it to
save and close it; save conflicts leave it open.

## Editor

- Ctrl A — select all
- Ctrl C, X, V — copy, cut, paste
- Ctrl Z — undo
- Ctrl Shift Z or Ctrl Y — redo
- Shift and arrow keys — extend selection
- Ctrl Left and Ctrl Right — move by word or punctuation segment
- Ctrl Shift Left and Ctrl Shift Right — select by word
- Ctrl Backspace and Ctrl Delete — delete a word or the selection
- Page Up and Page Down — move by one viewport in source
- Shift Page Up and Shift Page Down — extend selection by one viewport
- Home and End — beginning and end of a line
- Ctrl Home and Ctrl End — beginning and end of the note
- Double click — select a word
- Triple click — select a line

Command equivalents are handled on macOS, which has not been tested yet.
