# Keyboard shortcuts

## Workspace

- Ctrl O — open a vault by path
- Ctrl N — create a note
- Ctrl P or Ctrl F — search titles and contents
- Enter in search — open the first result
- Ctrl S — save the current note
- Ctrl Shift S — save a copy
- Ctrl W — save and close the current tab
- Ctrl E — cycle source, split, and reading views
- Ctrl Q — save all tabs and quit
- Escape — close a dialog

## Editor

- Ctrl A — select all
- Ctrl C, X, V — copy, cut, paste
- Ctrl Z — undo
- Ctrl Shift Z or Ctrl Y — redo
- Shift and arrow keys — extend selection
- Ctrl Left and Ctrl Right — move by word or punctuation segment
- Ctrl Shift Left and Ctrl Shift Right — select by word
- Ctrl Backspace and Ctrl Delete — delete a word or the selection
- Page Up and Page Down — move by one viewport in source
- Shift Page Up and Shift Page Down — extend selection by one viewport
- Home and End — beginning and end of a line
- Ctrl Home and Ctrl End — beginning and end of the note
- Double click — select a word
- Triple click — select a line

Command equivalents are handled on macOS, which has not been tested yet.
